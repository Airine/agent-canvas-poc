# 量化交易场景 · Canvas 多 Agent 协作 Demo

这是一份可运行的离线演示：五个角色围绕同一条量化研究流水线协作，覆盖
**产物发布 → 跨 Agent 读取 → 必要消息 → 暂停队列 → 风控签核 → 预算耗尽**。
它演示的是 Canvas 协作协议，不是投资策略，也不接行情、券商或模型。

- 运行时代码：`app/scripts/demo-quant-canvas/`
- 回归用例：`app/test/unit/quant-canvas-demo.test.mjs`
- 协议事实源：[Canvas 跨 Agent 协作](../canvas-collaboration.md)

```bash
# 仓库根目录；默认输出到系统临时目录
node app/scripts/demo-quant-canvas/run.mjs

# 指定输出目录
node app/scripts/demo-quant-canvas/run.mjs --out /tmp/quant-canvas-demo
```

运行后得到 `transcript.md`（审批与通信时间线、产物全文、通信边、指标）、
`edges.json`、`metrics.json` 和 `artifacts/A1..A8.md`。全程无网络、无依赖、
无真实标的，结果确定可复现。

## 角色与职责边界

| Agent | 职责 | 不应做的事 |
| --- | --- | --- |
| 组合经理 | 发任务卡、决定重跑、汇总人类待办 | 不代替风控签核，不把入队当批准 |
| 数据与因子 | 计算因子、标注数据质量 | 不生成订单，不静默填补陈旧数据 |
| 策略回测 | 执行回测、披露参数与指标 | 不判断能否上线，不改风控约束 |
| 风控合规 | 独立校验硬约束、给出 REJECT/签核条件 | 不复述回测口径代替检查，不放行陈旧数据 |
| 交易执行 | 生成纸面订单、检查参与率与成本 | 不实盘、不连券商、不自行加杠杆 |

每个角色只掌握自己读到的产物；没有共享内存或隐藏广播。角色之间真正传递的只有
不可变文本产物和消息队列。

## 在真实 Canvas 里怎么复现

1. 在同一画布创建 5 个真实会话，昵称分别用上表角色名；也可以只建组合经理，由它用 `canvas_spawn` 逐张派生其余四张卡（每次派生都需人工审批，深度和数量受配额限制）。
2. 点击昵称旁的复制按钮，取得 `@"风控合规"#xxxxxxxx` 形式的引用。hash 是身份，
   昵称只用于描述；改名不影响引用。
3. 在组合经理输入框输入 `@` 选择目标，粘贴任务卡内容。**选择引用不会自动发消息**；
   由该会话的 Agent 决定是否 `canvas_send`。
4. 每次 `canvas_read` / `canvas_publish` / `canvas_send` 都走当前会话审批。默认手动
   模式需要批准；辅助模式仍转人工；只有明确启用 Full Access 才按既有规则自动批准。
5. 读取与发送成功后，画布出现独立通信边：箭头是操作发起方 → 目标，读取与发送分道。
   提及、目录查询、待审批不会产生虚构连线。
6. 让风控会话暂停，再让组合经理发签核请求：消息显示“待发/已暂停”，不是“已消费”。
   恢复会话后还要明确恢复待发，随后才可能出现“已消费”。
7. 连续往返超过 4 跳或单轮 8 次发送会被拒绝；回到用户开新任务，不靠改写正文重置预算。

各角色的提示词可以直接取自剧本中的任务描述。要点是让每个 Agent **先读再判断**：

```text
请读 A2 与 A3，对照 A1 的硬约束独立复核。给出 REJECT/APPROVE 和最小修改集；
不要复述回测口径代替校验，不要修改 A2/A3，也不要生成订单。
```

## 这个 Demo 证明了什么

- 跨 Agent 的事实传递依靠带 SHA-256 的不可变产物，而不是聊天转述。
- 独立角色能发现上游遗漏：回测期末目标含 FFF，执行方按最新快照剔除并说明替代。
- 审批闸门能拦住敏感字段；被拒绝的调用不会留下“半发布”产物。
- `paused` / `pending` 只是排队事实；签核必须等真实消费与明确答复。
- 链预算与发送上限让协作在有限轮次内回到人类，不形成 Agent 间自动循环。
- 人类新任务可以开启新链并重置预算；Agent 不能靠改写正文或自称人类重置。
- Coordinator 在签核后不擅自放宽风险参数，而是用敏感性分析把取舍交回人类。

## 边界与不声称的能力

- 这是对 Canvas 工具语义的**本地模拟**，不是多进程 Pi 会话，也不调用模型。
- 行情是确定性合成数据；指标只用于演示流程，不构成投资建议或策略有效性证据。
- 真实 Canvas 工具不读取任意磁盘路径、思考块、工具日志或凭据；产物与正文上限
  12000 字符且 UTF-8 ≤16 KiB。
- 连线只是观测，不执行 DAG 调度、不自动建会话、不合并 Git、不扩大文件写入权限。
- 纸面计划不会发送到任何券商；实盘授权始终是人类的动作。

# 队列回执位置调整验收

## 行为

- `QueuePanel` 只在存在待发、提交中、未知或被拒绝条目时占用输入框上方区域。
- 全部条目已消费时，不再显示“已确认消费”归档条，也不重复展示已经消费的消息正文。
- 最近 5 条消费回执移到“会话状态与上下文”弹层中的“队列回执”折叠区；Agent 来源仍标注，完整状态继续由会话诊断承担。
- 有待发项时，队列面板仍提供编辑、排序、暂停/恢复和明确 Steer；回执不在队列列表中重复。
